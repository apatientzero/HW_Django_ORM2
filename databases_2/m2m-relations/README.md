
# Задание
## Итог по второму заданию («Связь многие-ко-многим»):
1. Модели: Созданы Article, Tag и промежуточная модель Scope с полем is_main.
2. Связь: Реализована через ManyToManyField(through='Scope').
3. Админка: Настроена inline-форма (ScopeInline) для удобного управления тегами.
4. Валидация: Метод clean() запрещает создание более одного основного раздела у статьи.
5. Сортировка: Метод get_sorted_tags() возвращает теги в правильном порядке (основной первый, остальные по алфавиту)
